# Cannabis aroma molecules — an interactive atlas

An interactive, fully-cited map of the molecules behind cannabis aroma: the ten major
**terpenes** (with live 3D structures you can rotate, change representation, and spin) and the
trace **non-terpene "flavorants"** — volatile sulfur compounds, thiols, esters, indoles —
that actually differentiate one cultivar's smell from another, and how they modify the terpene base.

Plus a short cross-domain detour: β-caryophyllene (the peppery aroma molecule that is *also* a
CB2 cannabinoid) opens onto a citation-graph analysis of the cannabis-and-dementia literature
(the linked second page).

**Live site:** https://denson.github.io/aroma-atlas/

Every chemical identifier is real (PubChem); the literature is real (OpenAlex, CrossRef-verified);
the 3D structures stream live from PubChem via 3Dmol.js. Aroma descriptors and recent-trial figures
come from grounded web search and are flagged as such on the pages.

Author: **Denson Smith** — a stoagen worked example. The underlying bio/chemistry skills build on
lamm-mit's ScienceClaw (Apache-2.0); these pages are original work.
